02

One mechanism, two selection styles

Default: include everything

No detector tags. Existing configurations and default behavior stay available.

Opt-out: subtract detectors

Existing omit_detector_* tags select upstream’s omitted implementations. Configuration imports can still retain SDK dependencies.

Opt-in: keep what you need

Global remove-all plus individual enable tags use those same implementation/stub files. Three targeted dependency fixes keep unused SDKs out.

Both tag styles remain supported. Omit wins when enable and omit conflict. Typed configuration stays in each detector package; the separate registration layer and detector config subpackages are no longer needed.

The measured prototype changes 100 files versus the earlier proposal’s 196, against the same upstream base. The landing update adds one regression-test file. The rebuilt Oracle and EC2 controls retain identical module sets and binary sizes. Size savings vary by selection; small increases are shown as measured.
